TruthLens is an explainable QA system built on TinyLlama 1.1B, fine-tuned using QLoRA on the SQuAD dataset. It detects hallucinations in real-time, scores answer confidence, and shows step-by-step reasoning — so users always know whether to trust the output. Built with HuggingFace, FAISS-based RAG, and deployed via Streamlit.
